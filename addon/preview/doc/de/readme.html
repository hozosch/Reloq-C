Eloquence-C-Hörtest

Dies ist ein früher, experimenteller Hörtest des unabhängigen C-Ports. Er ist noch keine NVDA-Stimme für den Alltag. Ihre gewählte NVDA-Stimme bleibt aktiv.

Installation und Bedienung

  1. Installieren Sie die Datei mit der Endung .nvda-addon über NVDA-Menü, Werkzeuge, Add-on Store, „Aus externer Quelle installieren“. Sie können die Datei auch im Explorer öffnen, während NVDA läuft.
  2. Bestätigen Sie die Installation und starten Sie NVDA neu. Die bisherige NVDA-Stimme bleibt ausgewählt.
  3. Drücken Sie NVDA+Strg+Umschalt+F11. Geben Sie einen Testtext in das Dialogfeld ein und bestätigen Sie mit Eingabe. NVDA+Strg+Umschalt+F10 bricht die laufende Vorschau ab.

Zum Einstieg ist Pappe. Packen. Tappen. im Eingabefeld vorbelegt. Diese mehrsilbigen Wörter entstehen aus gemeinsamen Lautregeln. Weitere geprüfte Beispiele sind Kette., Packte. Packten. Tippte. Kippte., Pack Tipp., Pack Pack., Papp Tipp., Pack Tipp. Hack Tipp., Pass., Tiss., Kuss., Bett., Deck., Guck., Bad., Mett., Mut., Nock. und Not.. Mett und Bett gehen jetzt auch ohne Punkt. Bei nicht abgedeckten Texten hören Sie mit Ihrer normalen NVDA-Stimme, ob ein Wort fehlt oder für eine erkannte Aussprache noch das Klangmodell fehlt.

Der Port spricht bisher nur einen kleinen Teil kurzer deutscher Texte mit 11.025 Hz. NVDA muss als 64-Bit-Prozess die mitgelieferte x64-DLL laden können. Die vorige Fassung konnte der Nutzer in ARM64EC-NVDA laden; auch x64-NVDA kann diese x64-DLL laden. NVDA 32 Bit und reines ARM64-NVDA werden nicht unterstützt. Bei einem Ladefehler meldet der Hörtest die Windows-Fehlerdetails. Die neue Fassung muss in NVDA noch gehört werden. Das Paket enthält ausschließlich den C-Port und Python-Steuerung, keine Apple- oder OpenEVV-Binärdateien.
