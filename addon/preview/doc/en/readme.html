Eloquence C listening preview

This experimental listening preview is not a general-purpose NVDA voice. Your existing NVDA synthesizer remains active.

Install and use

  1. In NVDA, open Tools, Add-on Store, Install from external source, and select the .nvda-addon file. Alternatively, open the file in Explorer while NVDA is running.
  2. Confirm installation and restart NVDA. Your selected synthesizer is unchanged.
  3. Press NVDA+Control+Shift+F11, enter text, and press Enter. NVDA+Control+Shift+F10 cancels preview playback.

Try these verified short texts, including punctuation: Pappe. Packen. Tappen. (pre-filled), Packte. Packten. Tippte. Kippte., Pack Tipp., Pack Pack., Papp Tipp., Pack Tipp. Hack Tipp., Pass., Tiss., Kuss., Bett., Deck., Guck., Bad., Mett., Mut., Nock., Not.. A final Mett or Bett also works without a period. Your existing NVDA voice reports whether an unknown spelling or a missing acoustic model prevented speech.

The C port currently covers only a small set of short German utterances at 11,025 Hz. NVDA must run as a 64-bit process capable of loading the included x64 DLL, such as x64 NVDA or ARM64EC NVDA on Windows ARM. The preview does not support 32-bit or pure ARM64 NVDA. It reports Windows loader details if the DLL cannot be loaded. The user confirmed that the previous preview loaded in ARM64EC NVDA; this updated build still needs a listening test. The package contains neither Apple nor OpenEVV binaries.
