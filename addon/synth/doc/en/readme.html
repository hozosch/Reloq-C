  • Never (default): automatic pauses unchanged.

  • Always: also shorten automatic pauses within the request.

Process ECI tags

Disabled by default; backticks and commands are then spoken literally. When enabled, supported commands are mixed SPR `[.1ha], spelling `ts0/`ts1/`ts2, prominence `0/`1/`2/`00, pitch `vb0…100, speed `vs40…250, volume `vv0…100, inflection `vf0…100, and pause `p0…60000.
