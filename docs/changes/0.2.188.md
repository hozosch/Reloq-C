# 0.2.188

- Large pronunciation dictionaries are released in address order. This removes repeated long searches in the memory allocator when replacing or disabling a dictionary. Local Linux measurements with the full US dictionary set improved from roughly 10 seconds to about 0.2 seconds for reloads, and from roughly 9 seconds to about 0.02 seconds for disabling. These are core measurements, not Windows/NVDA timings.
- Cancellation no longer waits behind native engine destruction in the language controller. The reported NVDA freeze still needs confirmation on the affected system.
- **Open dictionary folder** opens the existing `communityDictionaries` folder inside the add-on. Editor changes are monitored there; no additional editing directory is created in NVDA's main directory.
- Community updates refresh the installed files in that folder. Locally edited or removed volumes and selected own files retain precedence. Immutable worker snapshots live in an internal subfolder of the add-on; source-file preferences remain in the NVDA profile and can be read from the previous settings location.
- The repository has one English project README. It explains that NVDA is the first integration and current testing platform. Reducing size and resource use comes before the planned SAPI5 and Android integrations.
- Skipped Greek letters in Finnish/Korean sentences were traced by the user to NVDA symbol processing before the text reaches the core. No synthesis pronunciation changes were made for this report.

The dictionary context and case fixes from 0.2.187 are retained. No changes were made to the acoustic planner or agreed pronunciation choices.
