# 0.2.189

- Each used language now owns one native core shared by its eight voice
  presets. Changing voices no longer loads another copy of the same language
  and dictionaries. Only changed profile controls are applied on activation.
  User controls, cancellation and scoped language changes are preserved.
- A local Linux comparison of eight US voices followed in reverse, with the
  full community dictionaries, used one handle instead of eight. Peak RSS
  fell from 110,060 to 38,876 KiB (about 107 to 38 MiB). The complete sequence
  before closing took about 1.61 instead of 0.32 seconds; closing took about
  0.20 instead of 0.03 seconds. All 16 PCM length/hash pairs were identical.
  This isolates the Python controller against the same frozen C library;
  it does not measure NVDA on the user's device or promise that every remaining
  delay is fixed. Normal single-voice rendering has not been changed.
- Accented Latin words in Korean and Chinese use their existing native US
  foreign-word analysis. Windows-1252 letters retain their native identities;
  further Latin accents use the shared Unicode base-letter identities.
  Complete words, embedded digits, hyphens and native-script boundaries remain
  in the C word-analysis path. No caller-side text substitution was added.
  Existing ASCII/Pinyin behaviour and Japanese output remain unchanged in
  the regression comparisons. NFC/NFD and fragmented-input checks are included.
- The first offline Android ARM64 preview (`0.2.189-preview1`) adds a TTS
  service, 112 voice selections and an accessible test/settings screen around
  the same core. It supports Android 8+, all seven sample rates and native
  pause shortening. It includes a bounded streaming queue and cancellation
  scoped to the active request. Real Pixel/TalkBack testing is still pending;
  the optional dictionary manager remains NVDA-only. See the
  [Android instructions](../../android/README.md).

The user confirmed that 0.2.188 replaced freezing with occasional slow
responses. Further responsiveness, CPU and package-size work remains open.
The German acoustic planner, agreed pronunciation choices, dictionary-folder
behaviour and the earlier dictionary stability fixes are retained. There is
no runtime bytecode, original DLL/SYN, speech-result cache or test audio file.
