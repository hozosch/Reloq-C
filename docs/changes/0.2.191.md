# 0.2.191

- Android `0.2.191-preview3` adds the full set of voice/output controls:
  language, preset, rate boost, pitch, inflection, volume, male/female model,
  head size, roughness, breathiness, sample rate, pause policy and ECI tags.
  Voice values are saved separately for each preset. Independent switches
  choose Android-controlled or manually overridden speed and pitch; language
  and voice can also be fixed to the saved choice.
- The manual speed slider uses nominal words per minute, initially 190.
  Android supplies a relative request value with 100 meaning normal. Normal
  now maps to native 55 instead of 98. Scaling inverts the duration curve
  generated from the existing C table, so 2× requests approximately halve
  duration. Actual WPM varies with language, word length and pauses. Android
  pitch scaling follows physical F0; manual pitch keeps the native 0–100 range.
- Android now includes optional community dictionaries and a manager for
  linked own Dic files, priority ordering, manual reload and explicit updates
  from the current community master. Files enter the native dictionary stages
  with their original Windows-1252 bytes. Loading, merging and source checks
  run outside the speech worker. No file monitor runs without own sources,
  and the dictionary worker exits after 15 idle seconds. Editor changes are monitored when the file
  provider exposes modification time or size; manual reload works without
  that metadata. Incomplete updates retain the previous active snapshot.
- The JNI worker retains one core per used language, updates only changed
  parameters, and loads a changed dictionary snapshot when its language is
  next used. Request leases protect snapshots until synthesis finishes. Old
  unused snapshots can then be removed. No speech-result cache is introduced.
- Native PCM buffers are allocated per used language: 2,200 bytes for the
  first, compared with 30,800 bytes previously reserved for all fourteen.
  The 712,343-byte German supplemental lexicon is installed only when German
  is used and reuses a content-derived filename across app updates.
- Packages use DEFLATE level 9, preserving aapt2's uncompressed resource table.
  On the same NVDA payload this saves 177,919 bytes compared with level 6.
  The Android package grows overall because it now includes optional community
  dictionaries. These modest savings are not a claim of a large DSP speedup.
- Package identity and the preview signing certificate remain unchanged.
  The actual signed preview 2 and preview 3 APKs pass the new update check:
  `org.reloq.tts.preview`, same certificate, versionCode 20190 → 20191.
  Installing the APK updates the existing preview and retains its settings.

Validation includes 865 settings/dictionary-data checks, bounded streaming and
112 voice identifiers. All 33 JNI PCM length/hash pairs match direct C calls,
including customized female anatomy, 48 kHz, ECI tags and dictionary switches.
Three English passages measure about 174 WPM at normal and 353 WPM at 2×,
a 2.03× duration ratio. The existing language, dictionary semantics, retention,
queued reload/cancellation and both NVDA UI-language checks remain successful.
The actual NDK ARM64 register/stack check and APK install/signature/alignment
checks also pass. The full `make -C eci test` target passes, including 1,680
Asian/Greek renders and 105 pause comparisons. Its historical report writer
is now optional, and the English integration check uses the current shared
language owners. No audio files are written.

The user confirmed installation/basic Android speech and the previous US
responsiveness fix in 0.2.190. Preview 3's expanded settings, TalkBack navigation
and document-provider monitoring still need real-device validation. The C
acoustic rules and accepted language-specific sound choices are unchanged.
