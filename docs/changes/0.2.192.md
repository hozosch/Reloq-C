# 0.2.192

- Android `0.2.192-preview4` applies changes from checkboxes, lists and sliders
  immediately. The Save settings button is removed. Changes are persisted and
  used by the next synthesis request, including TalkBack feedback. Loading or
  resetting a profile suppresses intermediate writes, preserving separate
  values for each voice. Speech already submitted retains its request settings.
- Accented Latin letters in the Greek English analyzer stay within their
  complete lexical word. The existing US CP1252 accent entries and shared
  Unicode Latin identities are reused. Written-vowel alignment also recognizes
  the base identities of accented letters and ligatures. Greek character names,
  punctuation and the Greek pronunciation rules keep their existing paths.
- An isolated lowercase g in Chinese uses the same alphabet entry as character
  navigation and uppercase G. A g used as a unit after a number retains the
  native measurement grammar. English words keep their foreign-word path.
- Chinese lexical lookup checks the original Han spelling before its simplified
  compatibility form. For 38 traditional characters from ambiguous many-to-one
  families, folded candidates must retain a compatible source reading. A compact
  table generated from Unicode 17.0 Unihan supplies the identities; it does not
  replace the native word dictionary or add runtime Unicode-data files.
  This distinguishes 發/髮, 隻/只, 臟/髒 and 癥/症. Native neutral tones and
  contextual polyphony remain available, including 頭髮 and 甲殼. Single-character
  fallback uses the source character's default when the folded entry conflicts.
  One-to-one regional pronunciation differences are not imported wholesale.
- The bundled optional community dictionaries use the freshly resolved master
  `8e4561171d7561477023896b06593485146b86d8`. All seven files are verified against
  their Git blob hashes. Package identity and the signing certificate stay the
  same; the signed APK passes the upgrade comparison 20191 → 20192.

Validation includes 147 native text-component checks with a frozen old
romanizer source, 246 actual PCM/index comparisons for the changed paths,
366 CJK Latin/Unicode/fragment checks, and 40 language PCM/index comparisons.
The component tests verify word bytes, source identities, neutral tones,
polyphonic contexts, letter/unit routing and every UTF-8 byte split. The old
g and 髮 paths fail their respective new expectations. Canonical accent forms
and ECI fragments produce identical output. PCM remains in memory.

The new Android behavior still needs a real-device/TalkBack check. The user
confirmed the previous preview's layout. No DSP, German acoustic planner,
voice profile defaults or speech-result cache is changed by this release.
