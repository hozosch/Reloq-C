# 0.2.194

- German uses the built-in native C dictionary, as the other languages do.
  The separate 16,500-record, 712,343-byte supplemental lexicon is no longer
  shipped, loaded by the NVDA driver or installed by Android. Historical
  files remain regression/reference fixtures in the source repository.
- German abbreviation control now also reaches readings previously fixed
  in that supplemental data. Dotted initials retain their spelling, including
  spaces, and native C normalization chooses their reading and word count.
  The duplicate observed SPR abbreviation tables and spelling-expansion pass
  are removed. Main/Root user pronunciations remain independent of this switch.
- Ordinary cardinal quantities retain their original source spelling during
  sentence analysis. Phrase prediction can therefore apply the existing native
  rules to expressions such as “2 Minuten und 24 Sekunden”, including their
  word accents and inferred phrase boundaries. Authored numeric phones and
  onset policies remain with the independent acoustic planner.
- The sentence pass retains actual source whitespace between aligned words
  instead of feeding formatting blanks from an intermediate SPR annotation
  back into normalization. This also fixes contexts such as “Nr. 2”.
- The existing intact-ch compound correction resolves licensed native
  constituents without requiring an external lexicon. This retains
  Sprach-/Suchauswahl and their admitted inflections. The own German acoustic
  planner and accepted source/filter departures remain in place. In the
  curated 46-word comparison all phone sequences are retained; Übersicht
  now follows the native initial prefix stress.
- Android removes only generated old supplemental-lexicon copies on its worker.
  User dictionaries, settings, package name and signing identity remain.
- User calibration reference: German NVDA rate 38 is comfortable; Castilian
  Spanish and Greek require about 18. This is recorded alongside the controlled
  native duration measurements. No automatic rate normalization is introduced
  from a single listener reference or the six-syllable measurement.

All speech checks keep PCM in RAM and create no audio files. SAPI5 remains
planned. The new analysis behavior and the lexicon removal still require the
ordinary Windows/TalkBack listening check.

Validation: the complete ECI target passed, including 1,680 Asian/Greek renders
and 105 pause comparisons. The targeted suite passed 227 setting/tag/fragment/
character comparisons, 35 JNI/direct-C PCM pairs, 866 Android settings/data
checks, 25 dictionary semantics cases and 18 dictionary retention cases. Both
NVDA UI languages pass. The Windows ABI still has 21 exports. APK checks prove
the same package/certificate and versionCode 20193 → 20194. The final packages
contain no RLEX file or obsolete Android lexicon installer classes.

The NVDA package is 147,620 bytes smaller and the APK 151,616 bytes smaller than
0.2.193. An exploratory Linux sample shows lower initialization time and peak
RSS, but slightly higher warm synthesis/first-PCM medians; it does not establish
a general CPU or steady-latency improvement. Details and hashes are in the
[validation report](../validation/0.2.194.json).
