# 0.2.196

- German prose containing URLs retains native sentence analysis. URL
  hyphens no longer become suspended word constituents, and complete ASCII
  URLs retain their source identity across all generated phonetic groups.
  Reconstructing a multi-group token no longer repeats punctuation already
  present inside that token. This fixes the reported complete Heise/Quad9
  text, rather than adding word-specific pronunciation exceptions.
- The German phone sequence is allocated from its validated phone count,
  with space for affricate expansion, and parsed directly into private
  storage. The previous allocation used twice the entire annotation byte
  count and another temporary node array. Cancellation and invalid-input
  handling retain their transactional behavior.
- NVDA adds **Check for add-on updates** to its Eloquence C settings panel.
  Android adds **App updates**. Both check published GitHub Releases on
  request, stream downloads and verify size/SHA-256 before installation.
  NVDA verifies add-on name/version and uses its normal compatibility and
  confirmation flow. Android also verifies package identity and the current
  signing certificate, then hands the APK to Android's installer.
- No package releases have been published yet. The update controls report
  this state; subsequent update packages must first be published in GitHub
  Releases. Dictionary updating remains a separate action. No update polling
  or download work runs on the speech worker.
- The Android package/signature comparison supports updating directly from
  0.2.192-preview4 to 0.2.196-preview8, retaining the existing app identity.

The 4,000-word Linux heap test drops from 106,957,538 to 100,477,682 requested
live bytes, saving 6,479,856 bytes (6.06%) at the same PCM output. This is
requested heap space, not process RSS. The large acoustic target reservation
remains an optimization target. The Windows DLL remains approximately 56 MB;
this build's measured resource benefit is the smaller phone allocation.

The own German acoustic planner, documented sound departures and all
languages/voices remain. Tests keep PCM in RAM and write no audio files.
The new update controls and system installer handoff still need their
ordinary NVDA/TalkBack check when a package release is available. SAPI5 and
cross-language rate normalization remain pending.
