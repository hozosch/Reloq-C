# 0.2.200

Emoji names now work during ordinary speech in the shared C engine, including
Android. A compact index recognizes the 3,944 Unicode 17 RGI emoji and
sequences, including skin tones, joined emoji, flags and keycaps. It reuses
the existing localized CLDR name pools. No second name catalogue, platform
text replacement, Unicode runtime or network request is needed for speech.
Ordinary punctuation and digits keep their existing treatment. Explicit text
presentation and source boundaries are respected. The missing French name
for U+1FA8A is completed directly in the existing table from CLDR 48.2.

The private language provider no longer builds a second oscillator/filter
renderer, its wideband companion or its waveform coefficient tables. The
shared ReLoq C renderer owns PCM production. Parameter scheduling, source
indexes, language analysis and the selected German departures remain.
Small fixed-point helpers used by the existing I/O conversion boundary are
retained. Development frame-file taps are excluded from this release path.

All 10,896 native C rule entries are bound at link time through compact
name/function tables. Release descriptors no longer contain original object
names, instruction offsets or interpreter frame descriptions. The old
per-piece lookup arrays and the allocated rule-number index are discarded.
This removes 261,504 bytes of descriptor fields, as well as the redundant
lookup arrays and their initialization. Regular builds use checked-in C;
the maintenance generator reads C interfaces and does not require an original
module or a lifter. Existing linguistic rule bodies are unchanged. Their
remaining generated control flow and record layouts are still candidates for
further authored C work; this is not a claim that every rule has been rewritten.

The community dictionaries are refreshed from the current master of
`eigencrow/IBMTTSDictionaries`, commit
`1ecd298e87880131dad201378ac39a80940b342e`, with all seven Git blobs verified.
Android keeps its package identity and preview certificate for an in-place
update from 0.2.199-preview11. No new permission or runtime dependency is added.

The Windows DLL shrinks by 682,496 bytes to 54,544,384 bytes. The NVDA
add-on shrinks by 347,354 bytes to 19,508,738 bytes; the APK shrinks by
262,144 bytes to 17,446,294 bytes. All 196 language/rate/model PCM and index
comparisons remain identical to 0.2.199. The 110,432 localized emoji admission
checks also pass under ASan/UBSan; 504 public emoji cases verify the spoken
name, fragments and indexes inside sequences. JNI/direct comparisons pass
for 63 utterances. Warmed German heap peak for 4,000 words remains
58,628,850 bytes. CPU measurements remain exploratory and do not establish
a general device-latency improvement.

Package sizes, speech comparisons and measured limits are recorded in the
[validation report](../validation/0.2.200.json). PCM is hashed in RAM; no audio
files are created. The first public binary release and SAPI5 remain covered by
the [release plan](../RELEASE-PLAN.md).
