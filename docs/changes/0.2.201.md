# 0.2.201

All visible voice profiles and public ECI voice-tag presets now use volume
100. Explicit user volume remains controllable. The fixed, silent German
analysis requests retain their previous neutral settings: changing those
requests unnecessarily affected native phrase analysis in a regression test.

Short German pauses now keep the full acoustic plan and filter progression.
Streaming removes only the final run of exact zero samples inside planned
quiet intervals. Audible release samples and internal zero crossings are
preserved, including small female head sizes and breathiness. Explicit
pause tags retain their durations. There is no retained audio buffer.

Nine additional languages now use the same S-source increase against their
native ts reference as German and American English. Japanese, Castilian
Spanish and Greek keep their existing levels. Nine temporary doAF rule
frames are replaced with shared authored C. Latin American Spanish and
Portuguese read phone records from their actual slot 4; slot 2 contains
words in those modules. All 63 rate-specific S tests change as intended,
while the 63 vowel-only controls and all 196 duration/index pairs remain
unchanged. Ordinary PCM outside the intended S changes remains covered by
the separate build comparison.

The first **Windows x64 SAPI5 preview** registers one voice for each of the
14 languages. Its native settings dialog stores changes immediately for
the next utterance, without a Save button. It offers the eight profiles,
model, head size, pitch, inflection, roughness, breathiness, sample rate,
pause mode, speed boost, ECI tags, analysis options and dictionary folder.
SAPI supplies speed and volume. A lazy owner thread retains the initialized
language; eight small live PCM packets bridge it to SAPI's caller thread.
Cancellation also signals the C planner. Ordinary fragments stay connected,
and unsolicited word events are omitted. The package contains one ECI DLL
and the native installer, settings program and RAM-only activation test.

The production SAPI backend passes 113 host checks and matches direct ECI
PCM in 98 language/rate cases. Seventeen compiled layout comparisons match
the public Windows SDK. Actual Windows COM activation, installation and
keyboard/screen-reader operation still need practical testing. The preview
does not implement SAPI phoneme-ID input, SAPI lexicons, visemes or sentence
skipping. Engine edits and rate changes take effect on the next utterance;
volume and abort are handled during streaming. See [the SAPI guide](../../sapi/README.txt).

The community dictionaries use current master commit
`a23b0f9d9e64dc3156fb8c1795a7521bf173a285`, with all seven blobs verified.
Android keeps its existing package and certificate for an in-place update
from 0.2.200-preview12 to 0.2.201-preview13.

The Windows core DLL is 54,552,576 bytes, 8,192 bytes larger than 0.2.200.
The NVDA package is 19,509,897 bytes; the APK remains 17,446,294 bytes.
The SAPI ZIP is 19,547,910 bytes. The warmed German requested heap peak for
4,000 words remains 58,628,850 bytes. Exploratory paired Linux CPU medians
are mixed (about 0.983 at 11 kHz and 1.029 at 48 kHz, after/before). There
is no established general CPU or size win in this iteration. Further
authored C work on the remaining generated linguistic bodies remains useful.

The full C regression, 28 additional recipes, final 5,376 western-language
cases, 105 German pause-release triplets, both NVDA interface locales,
Android settings and 63 JNI/direct comparisons pass. PCM stays in RAM.
Hashes, measurements and preview limits are recorded in the
[validation report](../validation/0.2.201.json).
