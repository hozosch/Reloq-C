# 0.2.203

SAPI keeps Eloquence's selected synthesis rate when an application requests a
different output clock. For example, selecting 48 kHz in a SAPI application
while Eloquence is set to 11,025 Hz leaves an 11,025-Hz signal for SAPI or the
application to upsample. The engine does not add a resampler. `Speak` now
accepts only clocks that this engine actually advertised, rather than
silently selecting any of the seven acoustic profiles from its argument.
Previously negotiated formats remain valid if settings change. Changing the
Eloquence synthesis rate still requires format renegotiation or reopening the
voice. The initialized language and small streaming queue are unchanged.

The native installer now follows the supported Windows display language,
including its buttons and success/error messages. It uses the same twelve
translation tables as voice settings, including both Chinese scripts; other
Windows languages fall back to English.

The German frontend fixes a general loss of complete sentence analysis after
the supplemental lexicon was removed. Isolated admission and contextual
analysis could disagree about the spoken groups in quoted initialisms,
abbreviations, email addresses and local file URIs. A mismatch made the whole
utterance retry with simplified analysis, changing stress and sometimes the
pronunciation of unrelated words.

Token admission now retains real quote lookahead. Email addresses and general
URI schemes use the existing complete native token path. Punctuation adjacent
to the native quote delimiters uses the observed named-mark classification.
These changes keep contextual groups aligned without adding word exceptions
or restoring the separate lexicon. The German acoustic planner and documented
pronunciation departures are retained.

Validation uses the complete native C frontend as a linguistic reference;
the original Apple binary was not executed. Eleven whole-utterance fallbacks
were found in a 254-text corpus and corrected. A separate 72-case punctuation
matrix agrees in phones and prominence. The committed C regression compares
89 targeted contexts directly with the native frontend. PCM checks stay in
RAM throughout.

The x64 and x86 SAPI packages contain an expanded `Test-SAPI.exe`. It checks
that requests do not change the native rate, then exercises normal Windows
SAPI conversion into eight successive application formats for all fourteen
languages. It verifies stream formats and consistent duration without opening
an audio device or creating audio files. Host tests cannot execute Windows'
SAPI converter. The reported Windows conversion issue therefore still needs
practical verification; no successful Windows conversion run is claimed.

See the [validation report](../validation/0.2.203.json) for package hashes,
regressions and remaining limits.
