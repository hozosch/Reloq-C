# 0.2.205

This is the first GitHub package release, with an NVDA add-on, Android ARM64
preview APK and unified x64/x86 SAPI5 installer. See the
[release notes](../releases/0.2.205.md) for installation and current limits.

SAPI's Start menu entries explicitly include ReLoq C in the settings and guide
names. Changing the installer language rebuilds owned shortcuts while keeping
unrelated user links. The installer also supplies its normal removal shortcut.

German pause shortening keeps the original phone/control timeline but skips
the planned quiet body after a physical 3 ms source-silent budget in final-only
mode or 1 ms in always-short mode. It no longer renders milliseconds until
three completely zero PCM frames appear. Live filter and oscillator state
continues into the following word. Explicit pauses remain unchanged. This
also removes repeated curve validation during the numerical-zero wait.

German Root phonetics retain their underlying terminal consonants. Previously
the dictionary compiler synthesized them as complete isolated words and
stored the resulting allophones, losing final b/d/g/v/z before native suffix
analysis. The compiler retains native alias and syllable normalization while
restoring the authored terminal b/d/g/v/z in the lexical record. Native
complete-word analysis then applies final devoicing in context. Main aliases
and noncanonical phonetic input retain their existing parsing route. No word-specific Reader rule or
text-prefix replacement is introduced.

The release workflow collects all three installables only after platform
builds and Windows validation pass. Publication checks source identity, exact
asset names, lengths and SHA-256 digests, uploads a complete draft and then
publishes it. Build intermediates are not release assets.
