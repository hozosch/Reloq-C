# 1.0.1

Remove the additional +4-dB S/Z AF endpoint adjustment in German, American
English and the nine languages which later adopted it. The independent
English component planner also returns to native S/Z source levels.
Shared AF bindings retain their stream and boundary layouts while removing
the now-unneeded per-endpoint phoneme lookup. Native durations, other source
families and all three previously unmodified languages retain their values.

Native rule evaluation periodically samples its owning cancellation predicate.
An outer error unwind restores the arena frame cursor and landing depth;
nested language workers restore their parent ownership and inline queues.
The private phoneme reader clears partial data and returns after a failed
fetch, rather than retrying it forever during a pre-output abort.

The change improves interruption and next-request recovery, not initial
incremental synthesis of an uninterrupted long request. German text analysis
and target planning still precede its first PCM delivery. Measurements and
deterministic cancellation/recovery checks are documented in
[the text-response report](long-text-latency.md).

The engine reports 1.0.1.0, and all three installable packages use 1.0.1.
Android's version code is 1000001; app/add-on identities and Android signing
remain unchanged. Update selection covers upgrades from the official 1.0.0.
No listening-only wrapper, extra voice shelf, pulse change, S-spectrum
experiment or audio cache is included in release targets.
