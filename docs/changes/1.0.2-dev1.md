# 1.0.2-dev1: selectable high-rate hearing preview

This NVDA development package adds three live **High-rate tuning** choices:

- **A — Current sound:** the control, including the German ts level correction.
- **B — Native-16 consonants:** independent numeric 16-kHz parallel-bank colour
  in the common band, retaining the existing extension above 8 kHz and matched
  integrated noise energy. Broad p/f sources keep their existing path.
- **C — Native-16 consonants and gentle voice body:** B plus a periodic-only
  upper shelf, rising from 0.4 dB at 16 kHz to at most 2 dB at 48 kHz.

The selector leaves speech rate, pitch, language and anatomy unchanged. All
three settings are identical at 8 and 11.025 kHz. Noise and periodic shaping
are separate; C does not increase aspiration or frication. The reference is
an independently implemented numeric bank, not an included Apple recording.
No result cache, lookahead buffer or PCM resampling is added. The filters and
selected profile belong to each synthesis session, without process-global
listening state. This package contains one core DLL.

Long German text can start speaking after a completed admitted sentence,
without first planning every following sentence. A common native clock,
source indices and continuous DSP state preserve whole-text speech. Open
quotations, reporting clauses needing lookahead, explicit controls and
unbroken phrases keep their existing context requirements. This does not
promise immediate startup for a single arbitrarily long sentence.

The German ts frication now keeps its native contextual s level; its stop
burst remains native. Configured native volume is applied consistently to
all language modules. The private ECI adapter avoids a manufactured phrase
pause before inline speed/volume commands. New configurations retain the
1.0.1 behaviour of selecting NVDA's supported UI language on first use.

## Release gates

This is not the official 1.0.2 release. High-rate sound needs listening
acceptance. All reported issues are tracked before release, including the
seconds missing from English times/durations (#3), positional parameter
changes (#6), and the new Chinese speed/model contour report. Those follow-up
experiments are not represented as completed fixes in this package. Existing
Chinese pronunciation and pitch planning are retained in this preview.
