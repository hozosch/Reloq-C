# 1.0

The first official release is named **1.0** and packaged as **1.0.0** for
compatibility with existing update clients. NVDA and Android display the
regular product name. Their technical installation identities stay intact;
Android's versionCode advances to 1000000 with the existing certificate.

The British native dictionary now uses its LOT vowel in o'clock and the
electronic root. The same root supplies inflections and compounds, including
electronics, electronically and microelectronics. The native US dictionary
and acoustic models are unchanged. No additional runtime dependency is needed.

The three installables are rebuilt from the corrected shared core. Their
hashes and source identity are verified before publication. The superseded
test release is retained as an internal draft after the complete official
release has been published.

See the [release notes](../releases/1.0.md) for installation and limits.
