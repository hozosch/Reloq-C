# 1.1.0-rc3 — development candidate

The 16-kHz Classic Presence body now has periodic-source compensation and
less voiced aspiration. Higher rates retain that entire foundation and add
A's periodic upper body progressively (22.05, 32, 44.1, 48 kHz). The extra
branch contains neither aspiration nor frication. Periodic source fitting
uses the same bounded update/ramp policy as the main branch. A continuous
peak knee above 30000 catches isolated overshoots before PCM saturation;
ordinary samples keep their linear gain.

Castilian S/T keeps the accepted 16-kHz Classic consonants. At higher rates
it receives one quarter of the ordinary added upper-band AF power, rather
than either the complete extension or none.

Western and Greek embedded voice controls use the containing lexical word's
start, matching German volume controls. Pitch, speed, inflection, gender,
head size, roughness, breathiness and presets travel through the same
utterance without synthetic fragment pauses. CJK retains native segmentation;
redundant controls no longer change its sound or timing.

Long German requests can stream with dictionaries and ordinary volume,
pitch, roughness and breathiness controls. Anatomical/preset changes and
mixed tempos retain the complete plan: splitting those schedules still
changes anticipatory tract targets or a boundary F0 frame. Such requests can
therefore still have a longer start delay. Explicit SPR, spelling, language
and dictionary-policy changes also keep the complete transaction path.

The original host ECI.DLL in Eloquence_64 v25 was run on Windows as an API
reference. It has `eciSetVoiceParam` and `eciCopyVoice`, and no `eciSetVoice`.
The observed `eciSetDict` success return is 0; ReLoq now matches it.
This is a concrete API correction, not a claim of complete ECI parity.

Merged Android PR #8 is included. The interface has 12 locales covering all
15 supported dialects. Taiwan Mandarin is appended without moving existing
saved selections. There are 120 language/preset combinations. The APK keeps
the existing package and signing identity for updates.

The candidate still needs listening on the user's Windows ARM and Dell
machines. Automated PCM/range checks cannot establish that the remaining
audible stutters or the voice-body balance are resolved. Issue #1 remains
open; the root-license change for #4 takes effect on main when PR #9 merges.
