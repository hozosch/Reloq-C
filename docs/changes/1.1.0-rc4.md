# 1.1.0-rc4 — development candidate

The extended Classic B/C voice keeps its bass level instead of applying the
previous fixed -2 dB periodic trim. A +3 dB periodic presence shelf replaces
the +6 dB shelf and inverse sampled-source compensation. Aspiration and the
accepted consonant transfer keep their independent paths.

The source uses the actual 8/11.025-kHz glottal pole tables as anchors. Angle
and damping continue independently in physical frequency; the 11-kHz DC gain
is retained. At 16 kHz the source retains the 11-kHz physical poles. Above
16 kHz their extension grows with rate, alongside the existing gradual A-body
addition. This is a synthesis change, not upsampling finished speech.

Both the Classic foundation and its auxiliary A body now antialias glottal
closure. The latter previously retained the rounded, uncorrected closure.
Moving glottal and tract poles use coupled state only in the extended Classic
profiles. With fixed coefficients their all-pole transfer is unchanged; when
coefficients move, the unforced state contracts instead of injecting energy.
The existing final peak knee remains as protection: raw measurements still
find excessive peaks in some Castilian female/child and low-pitch settings.
Those cases are not solved by the source correction; a protected PCM peak
test must not be read as proof of distortion-free synthesis. Numeric ECI,
profile A, and the 8/11.025-kHz outputs retain their existing arithmetic.

Unknown backticks in ordinary technical text no longer disable early German
output. The initial admission probe is 96 rather than 512 bytes and grows
when no complete sentence has been admitted. A prosodic PERIOD alone is not
a cut: a real sentence stop must exist in the original source, so a semicolon
retains its connected following clause. Audio and source indices are compared
against the complete-text route, including code names and semicolons.

The tag issue remains open. rc3's comparisons established that an embedded
tag and a tag before its word agree; they did not establish that every tag
leaves all preceding audio unchanged. Pitch/inflection, speed, anatomy and
preset transitions still need that stronger causal-boundary correction.
Anatomy/preset changes, mixed tempos and lexical control contexts can still
require complete German analysis. This candidate does not claim those fixed.

Checks and host observations are recorded in
`docs/validation/classic-body-rc4.json`. Tests cannot establish the final
perceived body/richness balance on the user's NVDA/Windows ARM and Dell
machines. The user reported that rc3's stutters were gone; continuous source,
filter and callback state is preserved. Issue #1 remains open. PR #9 remains a draft; this is a listening candidate.

The NVDA add-on, ECI SDK and Android APK use the same source. Android keeps
its package/signing identity and advances its version code to 1090004.

The attempted phase rotations and replacement of the A auxiliary branch did
not fix all raw peaks, and are not part of this candidate. The general
`make -C eci test` also reaches an older generic-regression assertion that
rejects speed values 0 and 39, which the current ECI contract accepts; the
current API/rule/DSP checks are reported separately.
