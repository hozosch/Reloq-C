# 1.1.0-rc5 — development candidate

Classic B/C above 16 kHz now uses one periodic source and one physical vocal
tract. The auxiliary A voice and moving inverse tract fit have been removed
from this path. The additional oral resonances follow the same serial-pole
principle as the native 8/11-kHz transition, with broad bandwidths that narrow
gradually at the higher clocks. A fixed periodic-only equalizer restores the
low-clock colour. Aspiration does not enter that equalizer; the accepted AF
bank and Castilian S/T extension limits retain their separate processing.
The 16-kHz synthesis remains the foundation. Profile A and 8/11-kHz output
retain their established arithmetic.

The native 8/11-kHz difference is not simply a source brightness setting:
the number of oral poles, upper-pole limits/bandwidths, sampled source poles
and noise clocks also change. The new high-rate path uses physical source
poles without extrapolating their angle/damping beyond the measured tables.
It retains closure antialiasing and coupled-state pole transitions.

Extended-profile volume is now applied before PCM conversion and peak
protection. Previously, quiet playback could contain distortion made before
the requested attenuation. The final protection remains for exceptional
full-volume peaks; its bounded output is not evidence that raw synthesis
never overloads. Listening remains necessary to assess the reported rattle.

European-language inline voice controls now travel beside the unchanged
lexical sentence and take effect at the native word callback. Speed uses a
fractional duration accumulator; pitch, inflection, tract/source parameters
and presets act on subsequent frames without restarting the utterance.
API pitch and inline pitch select the latest word-scoped value rather than
multiplying two independent pitch factors. The new causal tests compare
every preceding sample and index with unchanged text, and require a real
following effect: 90 cases from default voices across ten languages pass,
along with 20 API/inline-pitch ordering cases. The older 725 queue
tests alone could not establish this property.

This is not a claim that all languages are complete. CJK uses a different
native word/index path; its causal tag timing remains open. German's older
pitch/inflection/model planning can still change earlier samples, despite
its better perceived volume boundary. Mixed-model phonetic calibration and
the zero-inflection-to-variable-inflection corner also need further work.

German admission no longer repeats lexical analysis for successively larger
windows containing no eligible sentence stop. Initial anatomy/preset tags
and redundant anatomy setters no longer force whole-text analysis. Real
later anatomy changes, mixed speeds, long individual sentences and open
quotations can still require a complete plan. Whole-text/stream comparisons
retain exact PCM and indices; arbitrary word-count cuts were not introduced.

The startup probe now compares warmed German and US-English engines, long
sentences, quotations and real control cases through the add-on transport.
These are local host timings with a simulated player, not Windows/NVDA or
audio-device measurements. Results and limitations are recorded in
`docs/validation/classic-body-rc5.json`.

ECI export names and the completed public compatibility layer are unchanged.
This remains a listening candidate, not the final 1.1.0 release.
