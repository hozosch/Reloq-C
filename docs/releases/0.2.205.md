# ReLoq C 0.2.205

The first public package release of ReLoq C brings the shared C speech engine
to NVDA, Android ARM64 and Windows SAPI5. It includes 14 language variants,
eight voice presets, seven synthesis rates from 8 to 48 kHz, live voice
controls, Unicode and CLDR emoji names, and optional pronunciation dictionaries.
Speech synthesis runs offline.

Download the package for your platform from the assets below:

- **NVDA:** install the `.nvda-addon` with NVDA 2026.1 or later in a 64-bit
  process. Select **Eloquence C (experimental)** as the synthesizer.
- **Windows SAPI5:** run the single `-setup.exe` installer. It installs x64
  and x86 voices together on compatible Windows and offers twelve installer
  languages. Find settings, the guide and removal under **ReLoq C SAPI5** in
  the Start menu. Each language has its own SAPI voice.
- **Android:** install the ARM64 `.apk` on Android 8 or later. Select
  **ReLoq C Preview** in Android's text-to-speech settings. Install over the
  existing preview to retain settings and update the same app.

Compared with the last test packages, German pause shortening now uses short
source-silent intervals like the other languages, without waiting for exact
zero audio samples. The original sound-release curves remain intact.
German dictionary roots retain their underlying voiced consonants until the
whole word is analysed: an entry ending in d now keeps d in **Reader** instead
of prematurely producing t. The rule also covers other voiced obstruents and
hyphen compounds.

SAPI writes on its own output thread and leaves sample-rate conversion to
SAPI or the application. Its selected Eloquence synthesis rate is shared by
all languages. No speech-result cache or temporary audio files are used.
NVDA and Android can check GitHub Releases for package updates on request;
their separate dictionary managers can update community dictionaries and
merge user files. SAPI uses a dictionary folder and detects edits between
utterances; it does not yet provide a dictionary-download interface.

The Android APK deliberately retains the existing **public preview signing
identity** for update continuity. It remains a preview build; a private
production signing identity and migration path are future work. Windows
components are native x64/x86 builds, not native ARM64. SAPI phoneme-ID input,
visemes and the SAPI lexicon editor are not implemented.

Automated checks cover native speech, dictionaries, cancellation, source
indexes, Android transport and Windows installation/removal, including SAPI
format conversion in memory on both architectures. Device listening remains
necessary to assess audible pauses and responsiveness. Please include a short
text, language, voice, sample rate and dictionary setting in reports through
[Issues](https://github.com/hozosch/Reloq-C/issues).
