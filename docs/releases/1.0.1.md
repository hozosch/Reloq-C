# ReLoq C 1.0.1

ReLoq C 1.0.1 restores the original S/Z source levels and improves how the
engine stops obsolete text analysis. The update is available for NVDA,
Android ARM64 and Windows SAPI5; the single SAPI installer includes x64
and x86 voices.

The additional 4-dB boost for unvoiced S and voiced Z has been removed from
the eleven language paths that used it. Japanese, Castilian Spanish and
Greek keep their existing levels. The accepted F/V/W adjustment remains.

Stopping speech now interrupts native rule analysis sooner instead of
waiting for a long, unwanted request to finish. Cancellation also restores
the language worker's frame state, including nested English analysis, so
the following request can reuse its initialized language and dictionaries.
A failed phoneme fetch no longer loops indefinitely during cancellation.
No speech-result cache is added.

This improves interruption and recovery. The initial analysis of an
uninterrupted long German request still depends on its length; the update
does not claim to eliminate all keypress-to-audio delay.

Further tuning of high-rate S colour and upper voiced harmonics remains
under listening evaluation. Those experimental changes are not part of
1.0.1. Apart from the accepted S/Z level rollback, the synthesis-rate
profiles retain their 1.0 behaviour.

Install the package for your platform over the existing installation to
keep settings and dictionaries. NVDA and Android can find the update through
their built-in package-update checks. The NVDA package retains its technical
filename prefix for compatibility with existing update clients; the
synthesizer is still displayed as **Eloquence C**.

See the [1.0 release notes](1.0.md) for platform requirements and existing
integration limits. Reports through [Issues](https://github.com/hozosch/Reloq-C/issues)
are most useful with the text, language, voice, sample rate and dictionary
setting.
