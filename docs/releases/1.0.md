# ReLoq C 1.0

ReLoq C 1.0 is the first official release of the shared C speech engine for
NVDA, Android ARM64 and Windows SAPI5. It provides 14 language variants,
eight voice presets, seven synthesis rates from 8 to 48 kHz, Unicode and CLDR
emoji names, live voice controls and optional pronunciation dictionaries.
Speech synthesis works offline.

Download the package for your platform:

- **NVDA:** install the `.nvda-addon` with NVDA 2026.1 or later in a 64-bit
  process, then select **Eloquence C** as your synthesizer.
- **Windows SAPI5:** run the single `-setup.exe` installer. It supplies x64
  and x86 voices together on compatible Windows, with twelve installer
  languages. The **ReLoq C SAPI5** Start menu group contains voice settings,
  the guide and removal.
- **Android:** install the ARM64 `.apk` on Android 8 or later and select
  **ReLoq C** in Android's text-to-speech settings.

Packages use the standard version **1.0.0**, so existing update clients can
recognize this release. Install over the previous test build to retain your
settings and pronunciation dictionaries. The NVDA add-on's technical identity
and filename prefix, and Android's package name and signing certificate, are
retained for in-place updates. User-facing experimental/preview labels have
been removed. Earlier test version numbers are not official release numbers.

British English now uses the normal British vowel in **o'clock** and the
**electronic** word family, including **electronics** and **electronically**.
The corrections are part of the native dictionary's phonetic data and retain
normal word analysis, inflection, compounds and sentence prosody.

The release also includes corrected German dictionary-root voicing, shortened
German pauses and the SAPI Start menu integration. NVDA and Android can check
for package and community-dictionary updates on request. SAPI detects changes
to its dictionary folder between utterances. SAPI leaves output-format
conversion to SAPI or the application; no speech results or audio files are
cached.

Windows components are x64/x86 builds, not native ARM64. SAPI phoneme-ID input,
visemes and its lexicon editor are not implemented. The Android package keeps
the existing public signing identity for update continuity; migration to a
private production signing identity remains separate work.

Please report problems through [Issues](https://github.com/hozosch/Reloq-C/issues),
including a short text, language, voice preset, sample rate and dictionary setting.
