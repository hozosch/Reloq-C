# ReLoq C 1.1.1

ReLoq C 1.1.1 is an update to 1.1.0 for NVDA, Android and Windows SAPI5. It improves SAPI responsiveness, reading of dashes and Japanese text, and dictionary-update feedback.

## Changes since 1.1.0

- **Faster SAPI response:** speech is prepared while earlier audio plays, improving response to interruptions and keyboard navigation. Actual timing depends on the application and device.
- **Dashes in running text:** em dashes and en dashes between words receive a sentence pause, including when there are no surrounding spaces. This addresses [issue #13](https://github.com/hozosch/Reloq-C/issues/13). Numeric ranges retain their previous treatment. The unspaced en-dash pause is an intentional improvement over Classic Eloquence.
- **Japanese and Chinese with SAPI:** word-position events no longer split native sentence analysis or introduce extra pauses. The same correction applies to direct ECI indexes in the shared CJK engine.
- **German underscore:** when the synthesizer receives the underscore as an explicitly read character, it uses the noun pronunciation. The existing context-sensitive treatment of the word in sentences is retained.
- **Dictionary updates:** a dialog in NVDA, Android and SAPI reports the numbers of new distinct entries and new dictionary files. Modified or removed entries and files do not count as additions. A first download reports totals; if the previous state cannot be compared, the dialog reports that the counts are unavailable.
- **Cleaned package identities:** the visible packages use the ReLoq C/Eloquence C names. The identifier changes for NVDA and Android require the one-time transition described below.

## Updating from 1.1.0

- **NVDA:** the new add-on has a different identifier, so it installs alongside 1.1.0. Back up any dictionaries edited inside the old add-on folder, disable or remove the old add-on, restart NVDA and select **Eloquence C**. The add-on requires NVDA 2026.1 or newer in a 64-bit process. Later installations with the new identifier update in place.
- **Android:** the new APK also has a different app identifier. Install it alongside the old app, select it in Android's text-to-speech settings, and set up voices and dictionaries again. Private settings and file permissions do not transfer between the two apps. Keep the old app until the transition is complete. The APK requires Android 8 or newer and an ARM64 device. It retains the project's publicly available test signing key; changing to a private key later requires an installation and migration plan.
- **Windows SAPI5:** run the installer to update the existing installation. It provides x64 and x86 voices on compatible Windows and keeps user settings and dictionary edits. These are not native ARM64 builds.

## Known limitations

- Japanese, Chinese and Korean source-position events may still arrive late, including at the end of an utterance. The change above prevents those events from affecting the speech; it does not yet make every position precise.
- Online dictionary updates currently retrieve a fixed set of supported filenames. Other new files in the source repository are not downloaded automatically.
- Confirmation from the reporter of [issue #10](https://github.com/hozosch/Reloq-C/issues/10) is still needed.

For changes introduced in 1.1.0, see the [1.1.0 release notes](https://github.com/hozosch/Reloq-C/releases/tag/v1.1).
