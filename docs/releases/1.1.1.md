# ReLoq C 1.1.1

ReLoq C 1.1.1 is an update to the shared speech engine for NVDA, Android and
Windows SAPI5. Compared with 1.0.1, it improves sound at higher sample rates,
pronunciation, responsiveness, dictionary handling and ECI compatibility.

## Sound and performance

- The sound at higher sample rates has been retuned to address reports of
  harshness and crackling while retaining a clear voice and consonants. German
  initial Z and ZW are less prominent in the male voice, and F and V have more
  energy from 22 kHz upward. All seven rates from 8 to 48 kHz remain available.
- High-rate filters use less processing time. Actual sound and responsiveness
  still depend on the device, voice, language and sample rate.
- SAPI prepares speech while earlier audio plays and responds faster when an
  announcement is interrupted. This improves keyboard navigation in NVDA and
  other SAPI clients. Actual timing depends on the application and device.

## Pronunciation and reading

- German now uses the shared native sentence and sound planner. Analysis of
  compounds, hyphens, slashes and pronunciation-dictionary entries has been
  improved. German R, final A, the glide in “Homepage”, nasal vowels, S and
  consonant combinations have also been refined. Questions receive a rising
  ending.
- American and British English can read seconds in times and durations,
  including fractional seconds. Other fixes cover formerly silent or
  incomplete words, French pronunciation, Spanish numbers and monetary
  amounts. Mandarin tone targets are more consistent across speaking rates
  and voice models.
- In English and other tested European languages, a long dash between words
  receives the native sentence pause even without
  adjacent spaces. An en dash between words receives the same treatment. The
  latter deliberately improves on Classic Eloquence's unspaced en-dash
  behaviour; ordinary numeric ranges retain their existing treatment.
- In Japanese and Chinese text, SAPI word marks no longer split the native
  sentence analysis or introduce extra pauses. The same fix also applies to
  direct ECI index marks in the shared CJK engine.
- In explicit German character reading, the underscore symbol is pronounced
  with the noun's stress. In running sentences the existing analysis still
  distinguishes the noun “der Unterstrich” from the verb “er unterstrich”.

## Voice controls and dictionaries

- Volume changes work in languages other than German. NVDA and ECI support
  speed, pitch and volume changes at the relevant point in an utterance. ECI
  voice tags can be used during speech without the extra pauses previously
  reported for speed and volume tags.
- NVDA, Android and SAPI5 support the Alternative IBM TTS Dictionaries as well
  as the existing community source. The alternative provides US English and
  Castilian Spanish, but no German dictionary. Personal entries and custom
  SAPI dictionary folders retain priority.
- Successful dictionary updates show a dialog with the number of new, distinct
  entries and the number of new dictionary files. Changes and removals do not
  count as additions. On the first download, the dialog gives both totals;
  if an earlier snapshot cannot be compared, it says the counts are
  unavailable. This feedback is available in the NVDA add-on, Android and
  the Windows SAPI settings. Online sources currently retrieve a fixed set of
  supported filenames; other new files are not automatically downloaded.

## Android and ECI integration

- Android settings are available in more languages. Direct Boot is designed to
  use protected copies of settings and dictionaries before the first unlock;
  a physical-device test of that scenario is still needed.
- ECI compatibility has been improved for language discovery, voice parameters,
  text encodings, dictionaries, callbacks, error handling, phoneme output and
  pause/resume. See the [ECI compatibility details](https://github.com/hozosch/Reloq-C/blob/main/docs/ECI-COMPATIBILITY.md)
  for supported behaviour and remaining differences.
- Package names and visible product identities use ReLoq C/Eloquence C names.

## Installation and migration

- **NVDA:** the add-on requires NVDA 2026.1 or later in a 64-bit process.
  The published 1.1 add-on and this 1.1.1 add-on have different identities,
  so both can be installed side by side. Back up dictionaries edited inside
  the old add-on folder, disable or remove the old add-on, restart NVDA and
  select **Eloquence C**. A previous installation with the new identity
  updates in place.
- **Android:** the APK requires Android 8 or later and an ARM64 device.
  The published 1.1 app has a different identity: install the new app alongside
  it, choose it in Android's text-to-speech settings, and set up voices and
  dictionaries again. Private settings and file permissions do not move between
  identities. Keep the old app until the transition is complete. An app
  already using the new identity updates in place. The APK retains the
  project's publicly available test signing key; changing to a private key
  later requires an installation and migration plan.
- **Windows SAPI5:** run the installer to update the existing installation; it
  provides x64 and x86 voices together on compatible Windows and preserves
  user settings and dictionary edits. These are not native ARM64 builds.

## Known limitations and feedback

Confirmation from the reporter of [issue #10](https://github.com/hozosch/Reloq-C/issues/10)
is still needed. Feedback on the sound at higher rates remains welcome in
[issue #1](https://github.com/hozosch/Reloq-C/issues/1). Please report other
problems with an example, platform, language, voice, sample rate and dictionary
setting.

Source-position events in Japanese, Chinese and Korean can still arrive late,
including at the end of an utterance. The change above prevents those events
from altering the speech; it does not yet make every position precise.
