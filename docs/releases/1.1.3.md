# ReLoq C 1.1.3

ReLoq C 1.1.3 updates the NVDA add-on, Android app and Windows SAPI5 voices. These changes are relative to 1.1.2.

## Changes since 1.1.2

- **Long text stability:** the speech engine no longer overruns its analysis stack on certain long passages, including the URL reported in [issue #19](https://github.com/hozosch/Reloq-C/issues/19) when NVDA does not preserve slashes. The original speech remains one utterance, without extra pauses inserted by the driver.
- **HTTPS addresses:** the native HTTP address reader now recognizes `https://` as well, while preserving HTTP handling.
- **Greek English path:** the choice of vowels for reduced English syllables is better aligned to spelling and pronunciation. Reduced t and d retain their written identities more reliably when a word has other t or d sounds before them. English /g/ uses the lowercase `g` phoneme.
- **Mandarin and English:** both mainland and Taiwan Mandarin initialize the shared English pronunciation data correctly, regardless of which language is selected first.
- **Application names:** the NVDA add-on, Android app and SAPI installer display names without the version number. The version is still available separately in the respective application or package information.

## Updating

The 1.1.3 packages retain the add-on identity, Android package name and signing certificate, and SAPI installer identity used by 1.1.2. They update 1.1.2 in place and preserve its settings and dictionaries. If upgrading directly from the published 1.1 NVDA or Android package, see the [1.1.1 transition instructions](https://github.com/hozosch/Reloq-C/releases/tag/v1.1.1) for the earlier one-time identity change.
