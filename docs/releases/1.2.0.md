# ReLoq C 1.2.0

ReLoq C 1.2.0 updates the NVDA add-on, Android app and Windows SAPI5 voices. The changes below are relative to 1.1.3.

## Voice and intonation

- **Mellow mode:** an optional setting reduces the intensity of the voiced sound around 3.5–4 kHz at sample rates of 16 kHz and above, while leaving frication and aspiration unchanged. It is off by default and is available directly after the sample-rate setting.
- **Question intonation:** German and American English can now use the original question contour. Select **Use original question intonation** in the voice settings. With the option off, the existing rising question endings remain. This addresses [issue #25](https://github.com/hozosch/Reloq-C/issues/25).
- **Volume:** speech is louder at the same volume setting, with improved handling of short peaks at higher speech rates. This addresses [issue #23](https://github.com/hozosch/Reloq-C/issues/23).

## Reading and pronunciation

- **Greek:** word and sentence prominence, connected speech and character names have been refined. The English pronunciation path and Greek letter combinations, including gamma-gamma, have also been improved.
- **English sentence endings:** a full stop following an individual letter can now end a sentence in contexts such as “written in C. NVDA …”, while common initials and abbreviations retain their handling. This addresses [issue #22](https://github.com/hozosch/Reloq-C/issues/22).
- **German:** the pronunciation of “Touch” has been corrected; personal dictionary entries retain priority.
- **SAPI5:** startup and recovery after interrupted speech have been revised to improve responsiveness.

## Dictionaries

The first utterance waits until the selected dictionary set is ready, including on SAPI5 and Android. The last valid set is retained if an update cannot be loaded. Selecting an already loaded dictionary and changing languages continue to use the fast reuse path.

The change for [issue #24](https://github.com/hozosch/Reloq-C/issues/24) is included, although the original report could not be reproduced locally. The reporter has kindly agreed to test the first announcement with this release; feedback remains welcome if the problem persists.

## Updating

The 1.2.0 packages retain the NVDA add-on identity, Android package name and signing certificate, and SAPI installer identity used by 1.1.3. They update 1.1.3 in place and preserve its settings and dictionaries. If upgrading directly from the published 1.1 NVDA or Android package, see the [1.1.1 transition instructions](https://github.com/hozosch/Reloq-C/releases/tag/v1.1.1) for the earlier one-time identity change.
