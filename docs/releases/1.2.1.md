# ReLoq C 1.2.1

ReLoq C 1.2.1 updates the NVDA add-on, Android app and Windows SAPI5 voices. The change below is relative to 1.2.0.

## Pitch scale

Pitch 50 is now Eloquence's normal pitch on all three platforms. Before, the pitch slider was sent unchanged to the engine, so slider 50 gave native pitch 50, which is clearly lower than the normal Eloquence pitch. The default Reed voice uses native pitch 65.

The pitch setting now uses one shared scale:

- 50 is native pitch 65, the normal pitch of the Reed voice.
- 0 to 50 covers native pitch 0 to 65; 50 to 100 covers native pitch 65 to 100.
- 0 and 100 remain the lowest and highest pitch.

This applies to:

- **NVDA:** the pitch slider in Speech settings, and NVDA's capital-letter pitch change, which is applied on the same scale.
- **SAPI5:** the **Base pitch** field of the ReLoq C settings dialog. A SAPI application's own pitch changes, such as NVDA's SAPI5 pitch slider, remain relative to this base pitch.
- **Android:** the **Manual pitch** slider. **Control pitch through Android** is unchanged: Android's normal pitch still uses the voice's own pitch.

The voice presets show their pitch on the new scale; for example Reed shows 50 and Shelly 73, and they sound as before.

## Updating

The 1.2.1 packages keep the NVDA add-on identity, Android package name and signing certificate, and SAPI installer identity of 1.2.0, and update 1.2.0 in place.

- **NVDA:** a pitch that was saved by selecting a voice (for example 65 with Reed) is converted once on the first start, so the voice keeps its sound. A pitch left at 50 now sounds at the normal Reed pitch. A different pitch you set yourself keeps its number and is read on the new scale; adjust it once if needed.
- **SAPI5 and Android:** saved settings are stored as native values and are kept unchanged. Only the number shown in the settings changes.
