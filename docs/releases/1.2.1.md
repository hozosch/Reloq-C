# ReLoq C 1.2.1

ReLoq C 1.2.1 refines the optional mellow mode in the NVDA add-on, Android app and Windows SAPI5 voices. The changes below are relative to 1.2.0.

## Voice

- **Mellow mode:** the reduction in voiced presence now extends towards 3 kHz, the extra richness is omitted at higher sample rates, and breathiness during voiced sounds is reduced. This creates a softer voice while keeping fricatives and unvoiced breath sounds intact.
- The option remains off by default and is available at sample rates of 16 kHz and above. The normal voice remains unchanged.

## Updating

The 1.2.1 packages retain the NVDA add-on identity, Android package name and signing certificate, and SAPI installer identity used by 1.2.0. They update existing installations in place and retain settings and dictionaries. If upgrading directly from the published 1.1 NVDA or Android package, see the [1.1.1 transition instructions](https://github.com/hozosch/Reloq-C/releases/tag/v1.1.1) for the earlier one-time identity change.
