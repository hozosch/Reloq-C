# ReLoq C 1.2.2

ReLoq C 1.2.2 adds an optional exact base pitch in hertz to the NVDA add-on, Android app and Windows SAPI5 voices. It also improves German pronunciation before pauses. The changes below are relative to 1.2.1.

## Pitch

- **Exact base pitch:** choose a whole-number value from 1 to 24,000 Hz. The normal ECI pitch scale remains available and unchanged. Set inflection to 0 to make the base easier to measure; tonal languages may retain their linguistic pitch contours.
- **NVDA:** enable the setting under NVDA settings → Eloquence C → Exact base pitch. Changing NVDA's normal pitch slider returns to the ECI scale and announces the change; the hertz value remains saved.
- **Android:** the choice is alongside the pitch slider when manual pitch is used. Android's own pitch control takes priority when enabled.
- **SAPI5:** choose hertz next to the pitch setting in the ReLoq C voice settings. A SAPI application pitch of 50 remains neutral; the chosen value is the base pitch and application pitch adjustments remain available.
- With ECI tags enabled, `` `vbhz150 `` sets a 150 Hz base for following text and `` `vb65 `` returns to the normal ECI scale. Tags do not alter saved settings.

The synthesis sample rate must exceed twice the requested frequency. Very high pitches may also be attenuated by the voice filters; an insufficient sample rate can distort the result or interrupt synthesis.

## Pronunciation and defaults

- **German:** the corrected final A is now used before commas, colons and other pauses as well as at the end of a sentence.
- **NVDA:** a fresh installation starts with pitch 65, matching the default Reed voice. Existing user settings are retained.

## Updating

The 1.2.2 packages retain the NVDA add-on identity, Android package name and signing certificate, and SAPI installer identity used by 1.2.1. They update existing installations in place and retain settings and dictionaries. If upgrading directly from the published 1.1 NVDA or Android package, see the [1.1.1 transition instructions](https://github.com/hozosch/Reloq-C/releases/tag/v1.1.1) for the earlier one-time identity change.
