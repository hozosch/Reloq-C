# ReLoq C 1.3.0

ReLoq C 1.3.0 adds precise speech-rate controls, optional word segmentation and dictionary migration in NVDA, and independent speech overrides for SAPI5 and Android. It also includes an optional NVDA equalizer and pronunciation fixes. The changes below are relative to 1.2.2.

## Speech rate and voice settings

- **Words per minute:** the original Eloquence `vwpm` timing is available across supported languages, including slower speeds. With ECI tags enabled, use `` `vwpm150 `` for 150 WPM and `` `vs50 `` to return to the ordinary ECI speed scale. Actual WPM depends on the language, text and pauses.
- **NVDA:** under NVDA settings → Eloquence C, the exact speech-rate option selects a value from 1 to 6000 WPM independently of the usual rate slider. Changing the normal rate or rate boost returns to that scale. Exact Hertz pitch and WPM settings now preview immediately; Apply and OK save them, while Cancel restores the last applied values.
- **SAPI5:** the ReLoq C voice settings can independently override an application's speed, pitch and volume. Speed can use either native ECI units or WPM; pitch can use the ECI scale or Hertz. These choices affect ReLoq C without changing other SAPI voices.
- **Android:** independently choose whether Android controls speed and pitch, or use ReLoq C's own ECI or WPM speed and ECI or Hertz pitch settings. Existing manual WPM values use the native timing rule after updating, so their audible speed can change.
- **ECI inflection tags:** the same inflection value now produces the same contour whether selected by a tag or the corresponding setting.

## NVDA word handling and audio

- **Dictionary import:** copy an NVDA speech dictionary from another synthesizer and assign the copy to a ReLoq language and one or all voices. The original remains unchanged; regular expressions, case sensitivity and comments are retained.
- **Unfamiliar English words:** an optional setting can split unfamiliar words into recognizable parts. Known words and dictionary entries take priority, and words that Eloquence would normally spell in uppercase retain that behavior. The feature is off by default.
- **Camel case:** a separate optional setting can split internal capital letters in all languages. User dictionary entries take priority.
- **Equalizer:** an optional three-band control adjusts bass, midrange and treble from -12 to +12 dB, with Balanced, Warm, Bright, Smooth and saved custom settings. Adjustments preview immediately. It is off by default; off or Balanced leaves the original audio unchanged. Boosts reduce the overall level to leave headroom.
- **NVDA Remote:** custom commands used by the new word handling are preserved when both computers use this version. The separate report about missing remote beeps and sound files remains under investigation.

## Pronunciation

Brazilian Portuguese now reads 12 and 19 with their usual vowels, including in larger numbers. The transition from the closed vowel into /z/ has also been adjusted.

## Updating

The packages retain the NVDA add-on identity, Android package name and signing certificate, and SAPI installer identity used by 1.2.2. They update existing installations in place and retain settings and dictionaries. If upgrading directly from the published 1.1 NVDA or Android package, see the [1.1.1 transition instructions](https://github.com/hozosch/Reloq-C/releases/tag/v1.1.1) for the earlier one-time identity change.
