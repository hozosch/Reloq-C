# ReLoq C 1.3.1

ReLoq C 1.3.1 adds a choice of acoustic timing on NVDA, SAPI5 and Android, improves SAPI dictionary management and fixes gaps in NVDA's optional English word segmentation. These changes are relative to 1.3.0.

## Acoustic timing

The new **Use original Eloquence acoustic timing (5 ms)** checkbox switches between the original 5 ms clock and ReLoq C's finer 1 ms clock. Rate and WPM values keep the same scales. Castilian Spanish and Greek default to 5 ms; other languages default to 1 ms. The choice is available for each language. In NVDA it is immediately after speed boost and also available in the settings ring. When SAPI's shared settings are enabled, a manual choice is shared across languages.

## Dictionaries and text

- **SAPI5 dictionary files:** Community dictionary downloads and merged data are stored under the current user's `%LOCALAPPDATA%\ReLoq C\SAPI5\Dictionaries` folder. Existing installed dictionary files are copied on first use and left untouched. Updates now use the source selected in the settings window.
- **SAPI5 personal dictionaries:** Choose **Own dictionary files** in voice settings, add one or more native `.dic` files, and select the language and Main, Root or Abbreviations volume for each. Later files override earlier files and community entries. The original files remain unchanged, and personal entries can be used without community dictionaries. Changes to the selected files are detected between utterances.
- **NVDA English segmentation:** The optional unfamiliar-word splitter can recognize additional pronounceable compounds from their known components. Existing pronunciation dictionaries still take priority, and Eloquence's native spelling of capitalized words is preserved.
- **Sentence boundaries:** A full stop after an isolated letter is recognized more consistently across languages, including before a number. When an initial before a name is indistinguishable from a sentence-ending letter in plain text, it may also receive a sentence pause.

The NVDA add-on, SAPI installer and Android package retain their previous identities and can update existing installations in place.
