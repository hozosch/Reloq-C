# ReLoq C 2.0.0

ReLoq C 2.0 adds Aragonese and improves number handling, accessibility settings and the NVDA add-on's translations. These changes are relative to 1.4.1.

## Languages and pronunciation

- **Aragonese** is available in NVDA, SAPI5 and Android, with its own pronunciation, number and character-name rules. It uses the same voice presets and controls as the other languages.
- Uppercase words followed directly by a number can use the word's normal pronunciation, for example “SAPI5” as “SAPI 5”, while existing complete dictionary entries and explicit spelling keep priority.
- US and British English treat uppercase and lowercase billion abbreviations alike in currency amounts, such as “$2B” and “$2b”.
- A voice change within an utterance no longer consumes digits at the start of the following text. This affects applications using the public ECI interface, including VoiceOver integrations.
- Isolated Unicode characters and emoji use localized character names while text in context retains its normal reading.
- Japanese moraic nasals no longer receive an unintended breath release. Sibilants are less sharp at higher sample rates.
- Mandarin gains contextual readings for more characters and phrases. Android adds options for numbers and automatic routing between scripts, including Japanese and Taiwan Mandarin.
- The Mandarin ECI interface accepts GB18030 input, including German umlauts, and honors explicit and shortened pauses after embedded English words. Chinese URL handling is preserved. Eloquence_64 bundles its own ReLoq library, so it needs an updated library to use these fixes. In the tested cases, ReLoq 2.0 follows the v28 32-bit host's pause commands without ReLoq-specific driver changes. The v28 text builder sends the same commands for some modes at Chinese punctuation on both backends, so those modes share the 32-bit host's limitation.

## Settings and translations

- The NVDA add-on includes translations of its interface and Eloquence category for Aragonese, German, Greek, Spanish, Persian, Finnish, French, Italian, Japanese, Korean, Brazilian Portuguese and both Chinese variants. The displayed names of the Eloquence languages retain their existing form.
- SAPI5 groups speed controls, application overrides and dictionary options more closely. Android separates voice and equalizer settings into their own screens, placing acoustic timing with the speed controls; Android speed and pitch overrides remain individually selectable.
- Speech during the first unlock after a restart was confirmed in earlier testing on a Google Pixel.
- Concurrent native engine starts have additional synchronization and memory-lifetime fixes.
- The source includes fixes contributed for iOS and Apple-silicon macOS: Apple ARM64 assembly, argument passing and cleanup of thread-owned frame memory. ReLoq Apple remains a separate application.

## iPhone, iPad and Mac

[ReLoq Apple](https://github.com/Quinton1110/ReLoq-Apple) provides system voices for these devices as a separately maintained app. See the installation instructions in [English](https://github.com/hozosch/Reloq-C/blob/main/docs/APPLE.en.md) or [German](https://github.com/hozosch/Reloq-C/blob/main/docs/APPLE.de.md). As of 23 November 2026, ReLoq Apple 0.1.5 bundles ReLoq C 1.4.1 with Apple fixes, not the 2.0 engine; it does not yet include Aragonese. Check the Apple project's releases for later updates.

## Known reports

A reported NVDA Add-on Store crash during rapid navigation and a possible switch to OneCore on restart have not been reproduced consistently; investigation continues in [issue #42](https://github.com/hozosch/Reloq-C/issues/42). Feedback on pause shortening and sound at higher sample rates also remains open. Persian speech is being developed separately and is not included in this release.

The NVDA add-on, SAPI installer and Android packages are intended to update existing installations while retaining settings and user dictionaries. On SAPI5, applications that group voices by Windows language may show Aragonese under Spanish, because Windows has no separate Aragonese language identifier for the voice catalogue.
