# ReLoq C 2.1.0

Changes since 2.0.0:

- Mandarin speech retains its intonation when ECI pauses are shortened. This also benefits applications such as Eloquence_64 once they use an updated ReLoq library.
- Uppercase words immediately before a number retain their normal pronunciation when more uppercase letters follow the number, as in `RICHEDIT50W`. Whole-word dictionary entries and explicit spelling retain priority.
- Linux x86-64 gains a Speech Dispatcher module for Orca and other clients, plus a separate Linda add-on. See the [Linux guide](https://github.com/hozosch/Reloq-C/blob/main/linux/README.md) for installation and requirements. ARM Linux and BT Speak Pro are not included in these packages.

The NVDA add-on, SAPI5 installer and Android packages are intended to update existing installations while keeping settings and dictionaries. Persian speech is still under development and is not included in this release.
