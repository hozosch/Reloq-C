# ReLoq C 2.1.1

Changes since 2.1.0:

- Explicit pitch changes can glide instead of jumping. The ECI command `` `vfg40 `` sets a 40 ms transition; integer values from 0 to 500 are supported, and `` `vfg0 `` turns it off. The value stays active across utterances and language changes until another `` `vfg `` command is received; it resets to 0 when the synthesizer restarts. Enable ECI tag processing in the application to use text tags. Ordinary speech melody is not additionally smoothed. (#50)
- With CamelCase splitting enabled, uppercase components in English words such as `radioWave` and `helpFile` receive the intended stress. In the NVDA settings, **Give dictionaries priority over camel case** is enabled by default; clearing it lets CamelCase splitting take priority over a whole-word dictionary entry. (#62)
- German Main dictionary entries are recognized inside typographic quotation marks, including text replacements with hyphens.

Known limitations: smoothing is not reliable in Chinese text mixed with Latin words or for NVDA pitch marks within Japanese text. A pitch tag can introduce an extra pause in some short Japanese kana sequences. Linux packages support x86-64; ARM Linux and BT Speak Pro remain outside the tested targets.

This release includes the NVDA add-on, SAPI5 installer, Android ARM64 and x86-64 packages, the Linux Speech Dispatcher module and the Linda add-on. Updates preserve existing settings and dictionaries.
