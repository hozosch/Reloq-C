# ReLoq C 2.1.3

Changes since 2.1.2:

- Corrected German compound boundaries in words such as “Schieberegler” and “Leserichtung”, and in related compounds. Explicit dictionary pronunciations retain priority.
- Corrected the German /ks/ sound in “wächst” and related “Gewächs” forms. The context “ihr wachst” is distinguished from “du wachst”.
- Improved the stress of English sentences in the Greek voice using the US English sentence analyzer.
- Greek names of symbols in text and in invalid phonetic input use the same pronunciation rules as ordinary Greek text.
- In the Greek voice, the Latin question mark `?` and Greek question mark `;` have distinguishable character names.
- In Greek and mixed Greek sentences, the question mark `;` produces question intonation. In entirely English sentences, it remains a semicolon.

These changes are in the shared speech engine and are available on all supported platforms.

Known limitations: smoothing is not reliable in Chinese text mixed with Latin words or for NVDA pitch marks within Japanese text. A pitch tag can introduce an extra pause in some short Japanese kana sequences. Linux packages support x86-64; ARM Linux and BT Speak Pro remain outside the tested targets.

This release includes the NVDA add-on, SAPI5 installer, Android ARM64 and x86-64 packages, the Linux Speech Dispatcher module and the Linda add-on. Updates preserve existing settings and dictionaries.
