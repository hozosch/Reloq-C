# eSpeak NG Persian rule sources

`fa_rules` and `fa_list` are copied unchanged from eSpeak NG commit
`688cb60368d6e0998f3632af8d1c3c2ad4191fc2`, by Shadyar Khodayari and Ehsan
Esmaili as named in the source headers. They are GPL-3.0-or-later; the project
GPL text is in `../../LICENSE`. These files provide the reference for the
experimental native Persian text frontend. They are not executed at runtime.
