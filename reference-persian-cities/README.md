# Persian place-name data

`iran-cities-filtered.json` is the `dist/json/cities-filtered.json` file from
[sajaddp/list-of-cities-in-Iran](https://github.com/sajaddp/list-of-cities-in-Iran),
commit `ace21bb251f96ced350bbc01541acffd71121feb`, Git blob
`74c8a821faee14b27fc954c917dc5a202e77a00b`. It is provided by that project
under GPL-3.0, whose license text is at this repository's root `LICENSE`.
The source includes Iranian city names and their administrative identifiers;
the generator uses only the names. It normalizes Persian letter variants and
deduplicates equal names. The data does not identify parts of speech or decide
whether a word has an indefinite enclitic: a place-name match is contextual
evidence for the corresponding adjective, not a general dictionary override.
