# Canonical Unicode names for Persian fallback

`derived-names-delta18.txt` is an extraction of Unicode 18.0.0's
`extracted/DerivedName.txt`: it contains the names absent or different in
the project's existing shared Unicode table and the standard algorithmic
name ranges. Hangul syllable names are already generated by the shared core.
`python-names-delta15to18.txt` contains the names added after Unicode 15,
and the same algorithmic ranges, for the optional Python fallback.

The original source is https://www.unicode.org/Public/18.0.0/ucd/extracted/DerivedName.txt,
SHA-256 `ac6cf808ea4ee29323031d5ba9449de13da51398a3f5ce401546d8fceb976df7`.
Its mirror's Git blob is `ff18343a5f73dccbd5b79f40f152dbba5d2f08fb`.
The Unicode License V3 is in `reference-cldr/persian/UNICODE-LICENSE.txt`.
